# colchicine-diabetic-gout-study
SAS code for nationwide cohort study of colchicine use and cardiovascular outcomes

# Colchicine and Cardiovascular Outcomes in Patients with Diabetic Gout

This repository contains SAS code used in the manuscript:

"Colchicine use was associated with reduced cardiovascular events in patients with diabetic gout without prior cardiovascular disease: a propensity-matched nationwide cohort study"

## Data Source

National Health Insurance Service (NHIS), Republic of Korea.

Due to legal and ethical restrictions, the underlying data cannot be publicly shared.

## Software

SAS 9.4

## Files

 colchicine.sas: Analytical code used for cohort construction, propensity score matching, and outcome analyses.
